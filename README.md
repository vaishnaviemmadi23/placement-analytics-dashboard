# Placement Analytics Dashboard

## Overview
The Placement Analytics Dashboard is an interactive data analytics project developed using Google Sheets. The project focuses on analyzing student placement data and visualizing important insights related to placements, company hiring trends, salary packages, and department-wise performance.

The dashboard simulates a real-world placement analytics system used by colleges and organizations for tracking placement statistics and student performance.

---

## Objectives
- Analyze placement records of students
- Visualize placement statistics using charts and KPI cards
- Understand department-wise placement performance
- Track company hiring counts and salary packages
- Practice data analytics and dashboard-building skills

---

## Dashboard Components

### 1. KPI Section
Displays high-level metrics for quick analysis.

### 2. Placement Analysis
Shows placed vs not placed students using charts.

### 3. Department Analytics
Analyzes student distribution and salary trends across departments.

### 4. Company Hiring Analysis
Displays the number of students hired by different companies.
